# 📜 @unifan/pi-sessions-zh (历史会话管理器·中文版)

为 **Pi Coding Agent** 打造的高颜值双栏历史会话选择器与实时预览恢复扩展。

---

## ✨ 核心特性

- **双栏分屏浏览**：左侧会话列表（带 Git 变更统计 `+2 ~3 -1` 与相对时间），右侧毫秒级**实时渲染对话内容**。
- **对话结构化展示**：支持区分 `◆ 用户`、`● 助手`、`◌ 思考过程`、`▸ 工具调用` 与结果折叠。
- **全中文交互体验**：界面提示词、相对时间（刚刚/X分钟前/昨天）、操作指引全面中文化。
- **零负担独立运行**：完全解耦自 `pi-agent-extensions`，不附带任何无用工具，零额外 Token 消耗。

---

## 🚀 安装方式

### 独立单独安装：
```bash
pi install D:/program/my/pi-unifan-zh/extensions/sessions
```
*(或者推送到 GitHub 后使用 `pi install git:github.com/你的用户名/pi-unifan-zh?path=extensions/sessions`)*

---

## 🎮 使用方法

在 Pi 中直接输入：
```text
/sessions
```

### 快捷键指南：
- **`↑` / `↓`**：在左侧列表中移动选择会话。
- **`Enter`**：**一键恢复并切换到所选会话**。
- **`Tab` 或 `←` / `→`**：在左侧列表与右侧预览窗之间切换焦点。
- **`t`**：展开 / 折叠工具执行详细输出。
- **`h`**：展开 / 隐藏模型思考过程（Thinking）。
- **`PgUp` / `PgDn`** 或 **`Ctrl+U` / `Ctrl+D`**：预览窗上下滚屏翻页。
- **`Ctrl+T` 或 `Alt+W`**：切换“仅当前工作区会话”与“全部工作区会话”。
- **`Esc`**：退出选择器，回到当前会话。
