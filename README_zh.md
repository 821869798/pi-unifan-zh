# 🌟 pi-unifan-zh (Pi 中文扩展全家桶与独立插件库)

专为 **Pi Coding Agent** 打造的高质量中文扩展合集与独立插件库。

支持 **“全家桶一键整包安装”** 与 **“按需单个插件独立安装”** 双模式架构。

---

## 📁 目录结构

```text
pi-unifan-zh/
├── package.json              # 根包配置（支持整包一键安装）
├── tsconfig.json             # TypeScript 配置
├── AGENTS.md                 # 开发者与智能体规范指南
├── README.md                 # English Documentation
├── README_zh.md              # 中文说明文档
├── extensions/               # 📦 独立插件集
│   ├── sessions/             # 📜 ① 历史会话管理器（双栏实时预览与恢复·中文增强版）
│   ├── review/               # 🔍 ② AI 代码审查套件（日常3专家 / 极速单兵 / 性能探针 / 全量会诊）
│   └── commit/               # 📦 ③ 智能 Git 提交助手（Conventional Commits 纯中文规范版）
└── skills/                   # 🎯 自定义技能库
```

## 🚀 安装指南

### 模式 A：一键安装整包（包含所有插件与技能）

#### 1. 通过 npm 在线安装（推荐 ⭐）：
```bash
pi install npm:@unifan/pi-unifan-zh
```

#### 2. 通过 GitHub 远程在线安装：
```bash
pi install git:github.com/821869798/pi-unifan-zh
```

#### 3. 本地开发调试安装：
```bash
pi install D:/program/my/pi-unifan-zh
```

---

### 模式 B：按需单独安装单个插件

#### 1. 仅安装 `sessions`（历史会话管理器·中文版）：
```bash
pi install npm:@unifan/pi-sessions-zh
```

#### 2. 仅安装 `review`（AI 代码审查系统·中文版）：
```bash
pi install npm:@unifan/pi-review-zh
```

#### 3. 仅安装 `commit`（智能 Git 提交助手·中文版）：
```bash
pi install npm:@unifan/pi-commit-zh
```

## 📦 扩展功能与核心命令

### 1. 📜 `sessions`（历史会话管理器·中文版）
- **命令**：`/sessions`
- **特性**：
  - 双栏全屏 TUI 视图（左侧选会话与 Git 变更统计，右侧毫秒级实时滚屏预览完整对话）。
  - 支持 `◆ 用户`、`● 助手`、`◌ 思考过程`、`▸ 工具调用` 与折叠。
  - 界面与时间提示（刚刚/X分钟前/昨天）全面中文化。
  - 零多余 Token 消耗，纯净轻快。
- **快捷键**：
  - `Enter`：一键恢复并切换到所选会话。
  - `t`：展开/折叠工具输出。
  - `h`：展开/隐藏思考过程。
  - `Tab`：切换左右面板焦点。
  - `PgUp` / `PgDn`：预览窗滚屏翻页。
  - `Ctrl+T` / `Alt+W`：切换全部工作区/仅当前项目。
  - `Esc`：退出选择器。

---

### 2. 🔍 `review`（AI 交互式代码审查套件·中文版）
- **架构亮点**：
  - 参考并融合了 **Codex 与 pi-agent-extensions**（Armin Ronacher @mitsuhiko）的经典架构。
  - **双执行引擎自由切换**：
    - ① **单模型深度审查（默认推荐）**：0 子代理依赖，0 网络断流，极速且 100% 稳定。
    - ② **多 Subagent 并发审查**：支持自由配置并发启动 **2、3、4、5、6** 个专家子代理协同会诊（Bug猎手、安全专家、性能探针、规范合规、注释质量、历史脉络）。
- **核心审查命令**：
  - **`/review`** 🔍 **（交互式全功能审查）**：唤起全中文 TUI 选择弹窗，支持 6 种审查模式与配置中心：
    - ① `审查未提交改动` (工作区已暂存 + 未暂存代码，智能默认推荐)
    - ② `与基准分支对比审查` (如与 main / master / dev 自动计算 merge-base 对比)
    - ③ `审查指定提交` (从最近提交历史中搜索挑选)
    - ④ `审查 Pull Request` (输入 PR 编号或 GitHub URL 本地自动检出审查)
    - ⑤ `审查指定目录/文件` (全量静态快照审查，非 diff)
    - ⑥ `自定义审查要求` (针对并发安全、GC/性能、指定接口等重点排查)
    - ⑦ `⚙️ 审查配置中心` (弹窗设置：单模型 / 多Subagent并发数 2~6 个)
  - **`/review-config`** ⚙️ **（审查配置中心）**：独立配置命令，随时切换审查引擎模式与并发数（配置自动保存在 `~/.pi/agent/pi-review.json`）。
  - **`/review-lite`** ⭐ **（极速单兵审查）**：无需弹窗，直接对当前工作区未提交改动做闪电审查（零多余前置步骤）。
  - **`/review-full`** 🚀 **（全量深度审查）**：直接对当前工作区与分支全部改动展开深度审查，严禁输出任何待办清单和环境测试，秒级直达 P0~P3 审查发现！
  - **`/review-sync`** 🔄 **（双会话审查接力闭环 · 自动识别角色）**：
    - **开发会话粘贴审查意见**：自动识别为【代码修复】，逐项核验有道理的立即改代码，有误报的给出解释，并输出结构化整改报告。
    - **审查会话粘贴修复报告**：自动识别为【只读复核】，结合 `git diff` 验证问题是否彻底解决且**严禁改动任何代码**，满意后输出 `✅【审核通过，可以提交代码】`！
  - **`/end-review`** 🏁 **（结束审查并返回）**：
    - 自动将审查分支中发现的 `[P0~P3]` 缺陷与待办事项生成结构化中文报告。
    - 一键平滑跳回主开发会话分支，并自动在输入框回填 `根据上述代码审查发现进行修改修复`！
- **极简高效，彻底告别繁琐步骤**：
  - 彻底干掉了任何“打印步骤待办清单（Checklist）”、“多轮执行 bash 测试文件”等冗余步骤，指令直达 `git diff`，直接输出代码发现。
- **命令行参数支持**：
  - `/review --subagents -c 2`：临时以 2 个专家并发启动审查
  - `/review --single`：强制单模型直接审查
- **审查准则与标准**：
  - **P0~P3 严格分级**：致命阻塞、紧急待修、普通建议、细节优化。
  - **严格过滤误报**：基于代码事实与真实 diff，杜绝主观臆测，重点排查并发竞态、内存开销、外部未受信输入与边界异常。
  - **支持项目定制规范**：自动识别并加载项目根目录的 `REVIEW_GUIDELINES.md`、`AGENTS.md` 或 `CLAUDE.md`。

### 3. 📦 `commit`（智能 Git 提交助手·中文版）
- **命令**：
  - **`/commit`**：自动分析暂存区/工作区代码变动（`git diff`），生成标准的 Conventional Commits 纯中文提交信息并 1 秒完成提交。
  - **`/commit-push`** 🚀：自动生成中文 Commit 提交，并**自动执行 `git push` 推送**到远端分支。
- **常用参数与用法**：
  - `/commit`：智能提交（有暂存只提暂存，无暂存自动暂存全量）。
  - `/commit -a` 或 `/commit --all`：自动强制暂存所有工作区修改（`git add -A`）并提交。
  - `/commit 修复了技能释放异常`：带提示词定向引导生成提交信息。
- **核心工程规范**：
  - **11 大标准分类**：`feat`, `fix`, `perf`, `refactor`, `ci`, `build`, `chore`, `docs`, `test`, `style`, `revert`。
  - **严格半角英文标点**：括号 `()` 与冒号空格 `: ` 严格使用英文半角字符，确保 CI / Commitlint 正则解析合规。
  - **严禁 Emoji**：保持严谨、专业的纯文本工程风格。
  - **智能自动变基（Auto Rebase）**：在 `/commit-push` 时，若远端有别人先提交的代码被拒绝，**自动在后台执行 `git pull --rebase` 变基并自动重试推送**，Git 历史保持一条干净直线！
  - **未推送提交自动同步**：即使当前工作区干净，若检测到本地有尚未 push 的历史 Commit，`/commit-push` 也会自动将其推送至远端！
